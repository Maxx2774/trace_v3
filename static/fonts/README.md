# Fonts

- **General Sans** (400, 500) is distributed by Fontshare under the
  [ITF Free Font License](https://www.fontshare.com/licenses/itf-ffl).
- **Instrument Sans** (variable 400–500, Latin) is distributed under the
  [SIL Open Font License 1.1](https://github.com/Instrument/instrument-sans/blob/master/OFL.txt).

The application serves these WOFF2 files locally from `/fonts` and makes no runtime font requests
to Google Fonts or Fontshare.
